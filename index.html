Typed Intent Routing Playground

Download the macOS Apple Silicon client for manual multi-turn routing tests and typed decision inspection.

Download v1.0.4

Install

Download the DMG, verify SHA256SUMS, open it and move the app to Applications.

Connect

Configure an authorized HTTPS typed API endpoint. The app does not bundle the backend, model or credentials.

Test

Run single turns, complete histories, digressions, resumes, multi-intent cases and guardrail previews from the playground.

Production boundary

turn + history → typed API → TypedDecision + Transition + DecisionState → agent pre-invoke

The client is a text-only operator surface. It does not call an LLM directly or execute business tools.
