Public distribution boundary

The playground is a client for an authorized typed-routing API, not the production agent runtime.

Public

This repository and its releases contain neutral documentation, the desktop installer, release notes, and checksums.

Private runtime

The API, semantic providers, model weights, retrieval data, credentials, customer data, session state, voice gateway telemetry, and business-tool execution remain server-side and are not bundled in the installer.

Safe installation

  1. Download the v1.0.8 artifacts.
  2. Verify SHA256SUMS.
  3. Install the app and configure an authorized API endpoint.
  4. Use the focused voice test surface only with an approved voice gateway.
